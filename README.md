Mission-critical operations hub and Kitchen Display System (KDS) for Olive Pizza restaurant branches.

---

## 🌟 Highlights

- **Live Orders with Persistent Alarms**: Real-time order buzzer with repeating audio chimes and pulsing high-visibility drawers until staff accepts the order.
- **Accurate Prep-Time Confirmation**: Configurable prep times (10-45 mins) syncing dynamically to customer apps and rider dispatch.
- **Durable Offline Action Queue**: IndexedDB action outbox that queues status transitions when internet connectivity drops and flushes upon reconnection.
- **Fleet Surveillance**: Live interactive map of nearby delivery partners and real-time delivery status.
- **Local Data & Backup Center**: Immediate JSON and CSV backup generator.
